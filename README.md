# VAM-Net

Official repository for **VAM-Net**, an audio-visual speech separation framework.

## Overview

VAM-Net is an audio-visual speech separation framework that leverages visual information to guide target speech extraction.

## 🎧 Audio Demo

Audio-visual speech separation examples on the **VoxCeleb2** dataset are available on our online demo page:

👉 **[VAM-Net Audio Demo](https://xyuguo.github.io/VAM-Net/Demo/Demo.html)**

The demo provides side-by-side listening comparisons of:

- Mixture
- Target Ground Truth
- Interferer Ground Truth
- RTFS-Net
- VAM-Net

## Visualization
